寒假学科营备课经验

Posted on 2024-02-01 Edited on 2024-08-20 Word count in article: 516 Reading time ≈ 2 mins.

前几天整理了一下1月份上学科营的内容，连续多天的课程为我后续进行批量大规模的备课提供了可借鉴的经验基础。

总的说来，有以下几点技术加持。

一是markdown相关。从Mathpix Snip到Typora再到vscode+marp流水线式“生产”讲稿以及课件以及答案解析，贯穿始终的md语法让一切操作都变得无比丝滑。

graph 
    A(Mathpix Snip) -->|截图和识别数学公式| B(Typora)
    B -->|编辑和格式化文档| C(VSCode+Marp)
    C -->|创建和预览幻灯片| D(最终讲稿和课件输出)
    
    style A fill:#e6f7ff,stroke:#5b8db8,stroke-width:2px
    style B fill:#fff0f6,stroke:#d35d6e,stroke-width:2px
    style C fill:#fffbe6,stroke:#f4b942,stroke-width:2px
    style D fill:#e8f5e9,stroke:#2e7d32,stroke-width:2px

二是AI相关。为了让课堂不单调，我尝试用GPT-4生成了一些谜语和插图。

比如讲韦达定理时，我本打算找一则相关的谜语，但是在网上找了一圈也没有发现合适的，于是让GPT-4写了一个：

在代数的海洋中，我是解的秘密钥匙；两个根的和与积，藏于系数之中。

还有关于放缩法的谜语：

在数学的世界，我轻巧舞动，缩小复杂，放大简明。在比例的游戏，我变换身影，我是何法，巧解难题？

以及几幅章节页的插图：

因为这几节课的核心在于“对称性”思想，所以这些插图虽然里面的符号看上去有些奇怪，但是整体的效果仍然很好地突出了主题。

谜语是简单的，插图是抽象的，这几节课同学们反馈的效果还不错，相当于是咖啡加糖，起到了恰到好处的调节作用。顺便再提一下上面的这个mermaid图也是GPT-4画的。😋
